# 测试计划与验收标准

**项目**：EEG-EmoStudio 脑电情绪识别数据制备与模型训练工作台  
**文档编号**：09  
**版本**：V1.0  
**日期**：2026-11-07  
**测试对象**：`eeg_emostudio/` V0.1.0、CLI、HTML 报告、DOCX/CSV 产物  
**测试环境**：Windows 11，Python 3.12.6，NumPy 2.2.6，pandas 2.2.3，PyTorch 2.9.1+cpu，无 CUDA

---

## 1. 测试目标

1. 验证 P0 需求是否按验收标准实现；
2. 验证数据清洗/选材结果与既有质量报告一致；
3. 验证 LOSO 无被试泄漏、指标计算正确、报告可读；
4. 验证异常输入被明确拒绝；
5. 为论文“系统测试”章节提供可复现证据。

## 8. 验收标准

### 8.1 软件验收（必须全部满足）

1. `python -m unittest discover -s tests -v` 全部通过；
2. `audit` 在真实数据上返回 0，计数与既有报告一致；
3. `select` 生成 80 条平衡清单，无 C/D；
4. `demo` 生成 HTML/JSON/PNG，标注合成；
5. `features` 能把合法 raw.npz 转为 features.npz + manifest；
6. `train` 能在合法特征上完成 LOSO，输出指标/检查点/报告；
7. 非法输入返回非 0，错误信息可操作；
8. 报告中无真实姓名。

### 8.2 科研验收（真实 EEG 到位后）

1. 通过 QG-EEG-1~6；
2. 至少 30 名被试（或公开数据同规模）；
3. LOSO 无泄漏，有代码断言；
4. 报告 ACC/BA/Macro-F1/κ/CI/混淆矩阵/分被试；
5. 主实验数字由冻结配置一次生成；
6. 合成数据不进入性能表；
7. 与至少 3 个基线同划分比较；
8. 消融覆盖双视角、原型数、正则权重。

### 8.3 文档验收

1. 00–14 文档齐全；
2. 需求-设计-测试追溯闭合；
3. 数字与 `metrics.json`/审计 JSON 一致；
4. Word 版目录/图表/页码正确；
5. 查重率低于学校要求。
