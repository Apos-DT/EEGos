## 1. 选题背景与意义

### 1.1 背景

情绪识别是人机交互、心理健康辅助、教育状态监测等应用的基础能力。基于面部表情、语音、文本的方法易受个体主动调节与表达歧义影响；EEG 直接记录大脑活动，具有客观、不易伪装、时间分辨率高的特点，是情绪识别的重要生理信号。

近年来，SEED、DEAP、MPED、FACED 等公开数据集推动了 EEG 情绪识别研究；跨被试域适应、域泛化、对比学习、图神经网络等方法不断涌现。但在实际科研中，仍存在三个突出问题：

1. **数据制备不可复现**：刺激材料如何筛选、问卷如何清洗、质量如何门控，论文往往一笔带过；
2. **标签不确定**：刺激预设情绪与被试实际体验不一致，离散标签与连续标签混用；
3. **评估易泄漏**：跨被试划分、标准化、早停/调参存在隐性泄漏，结果难以复现。

课题组已积累 240 条视频/音乐刺激、2,356 条预评价问卷和两套质量评分结果，但缺少一个把“材料—问卷—质量—EEG—特征—模型—报告”串起来的系统。

### 1.2 意义

- **科研意义**：为跨被试 EEG 情绪识别提供可审计的数据制备流程与无泄漏评估基线；
- **工程意义**：把分散脚本沉淀为可维护、可扩展、可复现的软件系统；
- **实践意义**：为后续跨刺激类型迁移、多模态融合研究提供数据与代码基础。

## 2. 国内外研究现状

### 2.1 数据与特征

SEED 使用 62 导 EEG 与电影片段，建立三类情绪范式；DEAP 使用 32 导 EEG 与 40 段 1 min 音乐视频，提供 valence/arousal 等连续评分；MPED 使用 62 导、28 段视频、7 类离散情绪；FACED 使用 32 导、123 名被试、28 段视频、9 类情绪。DE（微分熵）与 PSD 是常用特征。

### 2.2 跨被试方法

- 域适应：DDA、SSAS、CLISA、DMMR 等，通过对齐分布/对比学习/源域选择缓解个体差异；
- 域泛化：DMMR 等，在不访问目标域的情况下学习泛化表示；
- 图/原型：PCL-TDGCN、MIND-EEG 等，用动态图、多粒度、原型对比建模空间/类别结构。

### 2.3 不足

1. 数据制备细节缺失，质量门控不可复现；
2. 单视角/单原型难以覆盖脑区-电极多粒度与类内多模式；
3. 评估协议不统一，泄漏与单点精度问题突出；
4. 工程实现与科研分析脱节。

## 3. 研究目标与内容

### 3.1 目标

设计并实现 EEG-EmoStudio 系统，覆盖刺激筛选、问卷清洗、质量门控、EEG 预处理、DE 特征、数据集清单、LOSO 训练与报告；在此基础上验证双视角多原型方法的有效性。

### 3.2 内容

1. **数据制备**：审计 240 条材料与 2,356 条问卷；建立质量门控与四象限平衡选材；定义 raw.npz/features.npz 契约。
2. **系统实现**：CLI + 模块化流水线 + HTML 报告；防泄漏划分；数据哈希与 manifest。
3. **方法研究**：电极视角 + 脑区视角融合；类内多原型正则；与 MLP/DGCNN/EEGNet 对比。
4. **实验评估**：LOSO、ACC/BA/Macro-F1/κ/CI、最差被试、消融与失败分析。

### 3.3 关键问题

- 如何把“材料质量”转化为可执行规则？
- 如何保证全链路无泄漏？
- 双视角/多原型是否带来稳定性提升？

## 4. 研究方法与技术路线

### 4.1 研究方法

- 文献研究：综述 + 数据集论文 + 方法论文；
- 需求工程：访谈、用例、数据审计、SRS；
- 软件工程：分层架构、模块化、单元/集成测试、版本管理；
- 实验研究：LOSO、消融、统计检验。

### 4.2 技术路线

```text
文献/需求 → 数据审计 → 质量门控/选材 → 采集 → 预处理 → DE
→ 数据集/划分 → 基线 → DualView-MultiProto → LOSO/消融 → 论文
```

### 4.3 关键实现

- Python 3.11+，NumPy/SciPy/pandas/PyTorch；
- 文件型数据仓库 + NPZ + JSON manifest；
- 双视角模型：共享通道编码 + 通道注意力；区域池化 + 区域注意力；融合分类；
- 多原型：每类 K 个原型，紧凑性 + 类间 margin；
- 评估：OOF、bootstrap CI、分被试、混淆矩阵。

1. 可运行的 EEG-EmoStudio 系统（代码 + 测试）；
2. 数据审计报告与 80 条平衡选材清单；

4. 毕业设计论文；
5. 答辩 PPT 与演示。

**创新点**：

- 数据侧：质量门控 + 平衡选材 + 数据血缘；
- 方法侧：双视角 + 多原型；
- 工程侧：可复现训练评估一体化。

## 7. 可行性分析

- **数据**：240 条材料 + 2,356 条问卷 + 质量结果；SEED-IV 已接入作为真实数据基线；自采 EEG 在课题组设备上完成；
- **技术**：核心流水线已实现并通过 36 项测试（含 5 项 Web 测试）；合成 demo 可跑通；
- **经济**：开源栈，成本低；
- **风险**：自采 EEG/伦理可能延迟；已用 SEED-IV 公开数据兜底；
- **伦理**：知情同意、伪匿名、可退出、伦理备案。
