**项目**：EEG-EmoStudio 脑电情绪识别数据制备与模型训练工作台  
**文档编号**：10  
**版本**：V1.0  
**日期**：2026-11-07  
**适用读者**：数据管理员、实验员、算法工程师、课题组新成员

---

## 1. 系统是什么

EEG-EmoStudio 是一个命令行科研工作台，帮你完成：

1. 检查刺激材料、问卷、质量排序是否一致；
2. 从 240 条材料中按情绪四象限挑出平衡的实验材料；
3. 把分段 EEG 转成 5 频带 DE 特征；
4. 用固定、无泄漏的 LOSO 划分训练和评估模型；
5. 生成可直接放进论文/汇报的指标、图表和 HTML 报告。

它不负责：伦理审批、设备驱动、刺激版权、临床诊断。

## 2. 安装

### 2.1 环境要求

- Windows 10/11 或 Linux；
- Python 3.11+（推荐 3.12）；
- 内存 ≥8 GB；CPU 可运行；GPU 可选；
- 磁盘 ≥10 GB（不含原始媒体）。

### 2.2 依赖

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
# 可选：媒体时长探测
pip install opencv-python av
# 可选：原生 EEG 格式（V1.1）
pip install mne
```

### 2.3 验证

```powershell
python -m eeg_emostudio --version
python -m eeg_emostudio --help
python -m unittest discover -s tests -v
```

看到 `Ran 13 tests ... OK` 即环境正常。

## 4. 命令详解

### 4.1 `audit`：数据审计

```powershell
python -m eeg_emostudio audit --workspace . --out artifacts/audit
```

| 参数 | 默认 | 说明 |
|---|---|---|
| `--workspace` | `.` | 项目根目录（含 `山科数据集/`） |
| `--out` | `artifacts/audit` | 输出目录 |
| `--probe-media` | 关 | 读取媒体真实时长（慢，但能发现损坏/时长异常） |

**输出**：

| 文件 | 用途 |
|---|---|
| `audit_summary.json` | 全量机器可读结果 |
| `audit_report.md` | 摘要报告 |
| `video_ratings_clean.csv` / `audio_ratings_clean.csv` | 清洗后逐条评分 |
| `*_rater_table.csv` | 评分者统计 |
| `*_stimulus_coverage.csv` | 每条刺激覆盖 |
| `*_playback_issues.csv` | 播放问题明细 |
| `quality_combined.csv` | 240 条质量合并 |
| `*_mapping_audit.csv` | 映射/文件核对 |

**什么时候加 `--probe-media`**：首次入库、换设备、怀疑文件损坏、论文前最终核验。

### 4.2 `select`：平衡选材

```powershell
python -m eeg_emostudio select --workspace . --out artifacts/selection --per-class 10 --min-grade D
```

| 参数 | 默认 | 说明 |
|---|---|---|
| `--per-class` | 10 | 每个模态×象限选几条 |
| `--min-grade` | D | 最低允许等级（S/A/B/C/D） |
| `--modalities` | `video,audio` | 逗号分隔 |

**输出**：`selected_materials.csv`、`selection_summary.json`、`selection_report.md`。

**读结果**：

- 每层数量应相等；若有 `warnings`，说明某层不足；
- 默认不希望出现 C/D；若出现，检查 `main_issue`；
- 选材只解决“质量+平衡”，不替代预实验。

### 4.3 `features`：raw.npz → DE 特征

```powershell
python -m eeg_emostudio features `
  --raw data/raw/sub01.npz `
  --out data/features/sub01.npz `
  --fs 1000 --target-fs 200 `
  --window 1.0 --step 1.0
```

| 参数 | 默认 | 说明 |
|---|---|---|
| `--raw` | 必填 | raw.npz |
| `--out` | 必填 | 输出 features.npz |
| `--fs` | 文件内 | 原采样率 |
| `--target-fs` | 不重采样 | 目标采样率 |
| `--window` | 1.0 | 秒 |
| `--step` | =window | 秒 |
| `--aggregate` | mean | mean/std/concat |
| `--notch` | 50 | 工频 |
| `--no-notch` | 关 | 关闭陷波 |

**raw.npz 必须包含**：

```python
x        # (trials, channels, samples), float32, µV
y        # (trials,), int64, 0..K-1
subjects # (trials,), str
fs       # 可选，标量
class_names # 可选
```

**输出**：`features.npz` + `features.manifest.json` + `features.build.json`。

### 4.4 `train`：训练与评估

```powershell
python -m eeg_emostudio train `
  --data data/features/sub01.npz `
  --out experiments/sub01_loso `
  --model dualview --setting loso `
  --epochs 60 --batch-size 32 --lr 0.001 --seed 42
```

| 参数 | 默认 | 说明 |
|---|---|---|
| `--data` | 必填 | features.npz |
| `--out` | `artifacts/train` | 输出目录 |
| `--model` | dualview | mlp/dgcnn/dualview/eegnet |
| `--setting` | loso | loso/subject-dependent |
| `--epochs` | 60 | 最大轮数 |
| `--batch-size` | 32 | |
| `--lr` | 0.001 | |
| `--patience` | 12 | 早停 |
| `--seed` | 42 | |
| `--device` | auto | cpu/cuda |
| `--hidden` | 32 | 特征模型隐层 |
| `--dropout` | 0.25 | |
| `--prototypes` | 2 | DualView 每类原型数 |
| `--proto-weight` | 0.1 | 原型损失权重 |

**输出**：

| 文件 | 内容 |
|---|---|
| `metrics.json` | 总体/逐折/分被试/配置/环境 |
| `report.html` | 中文报告 |
| `figures/confusion_matrix.png` | 混淆矩阵 |
| `figures/per_subject_accuracy.png` | 分被试 |
| `checkpoints/fold_XX_*.pt` | 每折权重 |
| `oof_predictions.npz` | OOF 预测 |

**读指标**：

- 先看 `overall.accuracy` 与 `accuracy_ci95`；
- 再看 `per_subject` 的最差被试，不要只看均值；
- 看混淆矩阵，判断是否只学会多数类；
- 看 `n_subjects`/`folds`，确认不是单被试。

### 4.5 `demo`：合成演示

```powershell
python -m eeg_emostudio demo --out artifacts/demo --epochs 40 --model dualview --subjects 8 --per-class 30
```

**只用于软件验收/教学**，报告会明确标注。不要写入论文性能表。

## 5. 推荐科研工作流

### 5.1 阶段 A：材料准备

1. 把新问卷导出为 CSV；
2. 运行 `audit`，检查重复/编号/评分；
3. 运行 `select`，按 `per-class` 生成清单；
4. 人工试听/试看 10%，确认播放问题；
5. 冻结材料版本（记录 `selected_materials.csv` 哈希）。

### 5.2 阶段 B：采集

1. 被试签署知情同意；
2. 登记 `subject_id`（S01…）、年龄/性别/组别；
3. 按清单播放，确保事件标记与刺激 onset 对齐；
4. 每个 Trial 后完成 SAM/离散情绪自评；
5. 导出 EEG、事件、自评，立即备份。

### 5.3 阶段 C：数据整理

把每个 session 整理为：

```text
x: (trials, channels, samples)
y: (trials,) 0..K-1
subjects: (trials,) "S01"
fs: 1000
```

并记录通道名、单位、参考、滤波（如已做）。

### 5.4 阶段 D：特征与训练

```powershell
python -m eeg_emostudio features --raw ... --out ... --fs 1000 --target-fs 200
python -m eeg_emostudio train --data ... --out ... --setting loso --model dualview
```

### 5.5 阶段 E：论文

1. 从 `metrics.json` 取总体/逐折/分被试；
2. 从 `figures/` 取混淆矩阵；
3. 从 `report.html` 取配置与环境；
4. 在论文中写明数据版本、划分、预处理、随机水平、CI；
5. 合成数据结果只放在“系统测试”章节，不放在“实验结果”。

## 7. 常见问题

### Q1：`ModuleNotFoundError: No module named 'eeg_emostudio'`

在项目根目录运行，或：

```powershell
$env:PYTHONPATH = "."
python -m eeg_emostudio --help
```

### Q2：`SurveySchemaError: 未找到...列`

问卷版本变了。打开 CSV 看实际列名，在 `audit/survey.py` 的 `_require` 关键词中补充；或先把列名改成模板。

### Q3：`invalid_stimulus_ids` 不为 0

检查编号是否在 1–120、是否有 `0`/`121`/字母。系统只做显式别名，不做猜测；人工确认后在 `VIDEO_ID_ALIASES` 增加。

### Q4：音乐时长与 60 s 不一致

这是数据问题，不是软件问题。用音频编辑统一截 60 s，或修改实验协议；不要直接忽略。

### Q5：训练报 `存在未被任何折预测的样本`

通常是 `subjects` 有 NaN/空字符串，或标签/被试长度不一致。检查 NPZ。

### Q6：CUDA 不可用

默认 `--device auto` 会回退 CPU；若显式 `--device cuda` 会报错。CPU 可跑小模型。

### Q7：报告中文乱码

用浏览器打开 HTML；Markdown 用 UTF-8 查看器；DOCX 用 Word。若图中中文方块，安装微软雅黑/SimHei，或改 `reporting/figures.py` 字体。

### Q8：可以改标签编码吗？

可以，但必须：改数据字典、重跑全部实验、更新论文、升版本。禁止一半 0-based 一半 1-based。

### Q9：如何新增数据集？

写一个适配器，输出 `raw.npz`（x/y/subjects/fs/class_names），然后走 `features`/`train`。不要改训练核心。

### Q10：如何新增模型？

在 `models/` 新建 `nn.Module`，在 `registry.py` 注册，在 `tests/test_models.py` 加前向测试。
