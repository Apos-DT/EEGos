## 3. 数据审计详细设计

### 3.1 编号归一

输入：任意字符串/数字。算法：

```text
text ← strip(value)
if 无数字: return None
n ← 第一个连续数字
if kind == video:
    n ← VIDEO_ID_ALIASES.get(str(n), n)   # 388 → 38
    suffix ← ".mp4"
else:
    suffix ← ".mp3"
if n ∉ [1,120]: return None
return f"{n}{suffix}"
```

约束：

- 不做 `n mod 120`，避免把其他误写掩盖；
- 别名表是显式白名单，新增需审计；
- 返回 `None` 的记录进入 `invalid_stimulus_ids`，人工复核。

### 3.2 评分归一

```text
if value 是 1..9 数字: return float(value)
if value ∈ {"非常不愉快","非常平静"}: return 1
if value ∈ {"非常愉快","非常激烈"}: return 9
提取第一个数字; if 1..9: return
else: return None
```

**不在**解析阶段截断/四舍五入；越界值保留为 `None` 以便发现编码错误。

### 3.3 时间归一

支持：

- `"mm:ss"` → `mm*60+ss`；
- `"hh:mm:ss"` → `hh*3600+mm*60+ss`；
- `0≤x<1` 的数字 → `x*86400`（Excel 日分数）；
- 纯数字 → 秒。

### 3.4 播放问题归一

```text
parts ← split(value, "┋" or "|")
has_none ← "没有问题" in parts
tags ← []
for p in parts:
    if p == "没有问题": continue
    detail ← 提取〖...〗或原文
    tag ← classify_issue(detail)  # 损坏/无法播放/不同步/加速/模糊/杂音/音量/卡顿/内容/其他
    if tag not in tags: tags.append(tag)
severity ← 1 - ∏(1 - SEVERITY[tag])
if has_none: severity *= 0.9
return severity, tags, has_none
```

严重度表：损坏/无法播放 1.00、不同步/加速 0.90、模糊 0.80、杂音 0.65、卡顿/内容 0.60、音量 0.55、其他 0.50。

### 3.5 问卷字段识别

按关键词匹配，而非硬编码列索引，以适配问卷版本：

| 业务字段 | 关键词 |
|---|---|
| 评分者 | 姓名 |
| 刺激编号 | 视频编号 / 音乐歌曲编号 |
| 效价 | 效价 |
| 唤醒 | 唤醒 |
| 明确度 | 明确 + 主导情绪 |
| 主导情绪 | 请选择 + 主导情绪 |
| 覆盖时长 | 覆盖 |
| 稳定性 | 反转 |
| 熟悉度 | 熟悉 |
| 理解度 | 理解 |
| 播放问题 | 播放过程中 |
| 补充问题 | 未被上述 |

若必填列找不到，抛 `SurveySchemaError` 并列出实际列名。

### 3.6 清洗流程

```text
1. 读取 CSV（UTF-8 BOM，dtype=str）
2. 识别列 → 构造规范 DataFrame
3. 归一 rater/stimulus/valence/arousal
4. 解析问题文本
5. 按 submitted_at,row_id 排序
6. drop_duplicates(rater, stimulus_id, keep=first)
7. 逐评分者统计 n/mean/SD/中位时长/直线作答
8. 逐刺激统计覆盖/均值/SD/问题率
9. 输出清洗表/摘要/问题明细
```

**直线作答判定**：`valence_sd < 1.0 AND arousal_sd < 1.0`。只标记，不自动删除；质量评分阶段可剔除。

### 3.7 质量表读取与选材

质量表字段映射：视频编号/音乐歌曲编号→`stimulus_id`，质量总分→`quality_score`，质量等级→`grade`，情感类别→`category`。

选材：

```text
for modality in modalities:
  for category in [HVHA,HVLA,LVHA,LVLA]:
    candidates ← 表中 modality/category 匹配且 grade ≤ min_grade
    sort by (grade_order, -quality_score, stimulus_id)
    take first N
    if <N: warning
```

复杂度：`O(M log M)`，M=240，可忽略。

## 4. 预处理与特征详细设计

### 4.1 预处理

输入 `x` 形状 `(C,T)` 或 `(N,C,T)`。

1. 校验 fs、带通边界；若 high ≥ Nyquist，则 high ← 0.95·Nyquist；
2. 4 阶 Butterworth 带通，`sosfiltfilt`（零相位）；
3. 50 Hz 陷波：`iirnotch(w0=50, Q=30)` + `filtfilt`；
4. 可选 CAR：`x - mean(x, axis=channels)`；
5. 可选重采样：`resample_poly(x, up, down, axis=-1)`，`up/down` 由目标 fs 与 fs 的最大公约数得到；
6. 可选幅度剔除：`ptp(x, axis=-1) ≤ threshold`。

**边界**：不补零；epoch 越界直接丢弃。补零会引入虚假高频/低频成分。

### 4.2 DE 特征

对每个 trial、通道、频带、窗口：

\[
DE = \frac{1}{2}\ln(2\pi e \sigma^2)
\]

其中 \(\sigma^2\) 为带通信号在窗口内的方差，\(\sigma^2\) 下限 \(10^{-12}\)。

流程：

```text
for band in {delta,theta,alpha,beta,gamma}:
    filtered ← sosfiltfilt(bandpass(band))
    for start in range(0, T-window+1, step):
        var ← variance(filtered[..., start:start+window])
        de[..., band] ← 0.5*log(2*pi*e*max(var,1e-12))
```

输出 `(N, W, C, B)`；聚合 `mean/std/concat` 后 `(N,C,B)`。

窗口/步长默认 1.0 s / 1.0 s；论文需报告实际值。

### 4.3 PSD 对照

Welch 法，`nperseg=1s`，对每个频带积分功率并取对数，输出 `(N,C,B)`。用于稳健性对照，不进入主模型。

### 4.4 标准化

**只在训练折拟合**：

\[
z = \frac{x-\mu_{train}}{\sigma_{train}},\quad \sigma_{train}=\max(\sigma_{train},10^{-8})
\]

均值/方差按 `(samples, channels, bands)` 逐通道/频带计算；验证/测试使用同一组参数。禁止全量标准化。

`manifest` 字段：

  "subject_counts": {"S01": 120, "...": 120},
  "sessions": [],
  "generated_at": "..."

### 5.2 LOSO 划分

```text
for test_subject in sorted(unique(subjects)):
    test ← indices(subjects == test_subject)
    pool ← indices(subjects != test_subject)
    train, val ← stratified_holdout(pool, y, val_fraction, rng)
    assert train∩test = ∅ and val∩test = ∅
    yield fold
```

`stratified_holdout`：

```text
for cls in unique(y[pool]):
    idx ← shuffle(pool[y==cls])
    n_val ← clamp(round(len(idx)*fraction), 1, len(idx)-1) if len≥2 else 0
    val += idx[:n_val]; train += idx[n_val:]
```

**边界**：若某类只有 1 个样本，验证集可能为空；此时回退用训练集做早停，并在报告中标记“退化折”。

### 5.3 被试依赖划分

分层随机切 test（20%），再从剩余切 val（20%）；允许同一被试跨集合，因为研究问题不同；报告中必须明确设置。

### 5.4 泄漏断言

```python
train_subjects = set(subjects[train_idx])
test_subjects = set(subjects[test_idx])
assert not (train_subjects & test_subjects)
```

验证集同样断言。该断言在每次 LOSO 折执行。

## 6. 模型详细设计

### 6.1 MLP 基线

输入 `(B,C,F)` → Flatten `(B,C·F)` → Linear(128) → GELU → Dropout(0.3) → Linear(128) → GELU → Linear(K)。参数量约 `C·F·128`。

### 6.2 DGCNN 基线

1. `h = Linear(F→H)(x)`；
2. 余弦相似度 `S = normalize(h)·normalize(h)^T`；
3. 每节点保留 top-k，mask 后 softmax 得邻接 `A`；
4. `h ← GELU(LayerNorm(A·Linear(h) + h))`，重复 2 次；
5. 拼接 max-pool 与 mean-pool → MLP → K。

复杂度 `O(B·C²·H)`；C=62 时可接受。

### 6.3 DualView-MultiProto（提出方法）

#### 6.3.1 电极视角

对每个通道共享编码：

\[
e_i = \mathrm{GELU}(W_e x_i + b_e), \quad
\alpha_i = \mathrm{softmax}_i(v_e^\top e_i), \quad
z_e = \sum_i \alpha_i e_i
\]

#### 6.3.2 脑区视角

把 C 个通道按连续顺序分成 R=5 组（额/中央/顶/颞/枕的近似；真实 montage 可在 V1.1 用通道名映射）：

\[
r_j = \frac{1}{|G_j|}\sum_{i\in G_j} x_i, \quad
u_j = \mathrm{GELU}(W_r r_j + b_r), \quad
\beta_j = \mathrm{softmax}_j(v_r^\top u_j), \quad
z_r = \sum_j \beta_j u_j
\]

#### 6.3.3 融合与分类

\[
z = \mathrm{Dropout}(\mathrm{GELU}(W_f[z_e;z_r]+b_f)), \quad
\hat{y} = W_c z + b_c
\]

#### 6.3.4 多原型正则

每个类别 K 个原型 \(p_{c,k}\in\mathbb{R}^H\)，L2 归一化。样本 \(z_i\) 与原型距离：

\[
d_{i,c,k} = \| \bar{z}_i - \bar{p}_{c,k}\|_2
\]

\[
\mathcal{L}_{proto} = \frac{1}{N}\sum_i \min_k d_{i,y_i,k}
+ \frac{1}{N}\sum_i \max\left(0, m - \min_{c\ne y_i,k} d_{i,c,k}\right)
\]

总损失：

\[
\mathcal{L} = \mathrm{CE}(\hat{y},y) + \lambda \mathcal{L}_{proto}
\]

默认 `K=2, λ=0.05–0.1, m=1.0`；消融时分别设 `K=1`、`λ=0`。

#### 6.3.5 复杂度

参数量约 `F·H + H + F·H + H + 2H·H + H·K + H·K_proto`，远小于大型 CNN；CPU 可训练。

### 6.4 EEGNet 基线

标准结构：时间卷积（F1=8, kernel 15）→ 深度可分离空间卷积（D=2）→ 平均池化 → 可分离卷积（F2=16）→ 全局平均池化 → 线性。输入 `(B,C,T)`，内部加通道维。

## 7. 训练与评估详细设计

### 7.1 训练流程

```text
set_seed(seed)
for fold:
    x_train,x_val ← standardize(train/val)
    model ← build_model(...)
    criterion ← CrossEntropyLoss(weight=class_weights)
    optimizer ← AdamW(lr, weight_decay)
    scheduler ← CosineAnnealingLR(T_max=epochs)
    best ← ∞
    for epoch:
        model.train()
        for batch:
            logits ← model(x)
            loss ← CE(logits,y)
            if dualview and λ>0:
                z ← model.embed(x)
                loss += λ * proto_loss(z,y)
            backward; clip_grad_norm(5.0); step
        scheduler.step()
        val_loss ← eval(model,val)
        if val_loss < best: save state; stale=0
        else: stale+=1; if stale≥patience: break
    restore best
    pred ← predict(test standardized)
```

### 7.2 类别权重

\[
w_c = \frac{N}{K\cdot n_c}
\]

用于缓解类别不平衡；不重采样测试集。

### 7.3 指标

- Accuracy = 对角线和 / 总数；
- Balanced Accuracy = 各类召回率均值；
- Macro-F1 = 各类 F1 均值；
- Cohen's κ = `(Po-Pe)/(1-Pe)`；
- 95% CI：1,000 次 bootstrap 的 2.5%/97.5% 分位；
- 分被试指标：按 `subjects` 分组计算 ACC/Macro-F1。

### 7.4 OOF 汇总

每个测试样本恰好被留出一次；把所有折的预测拼成 OOF 向量，再计算总体指标。禁止“各折指标平均”替代 OOF（样本量不同会偏）。

### 7.5 检查点

```python
torch.save({
  "state_dict": model.state_dict(),
  "config": asdict(config),
  "fold": fold,
  "test_subject": subject,
}, path)
```

加载时必须同时校验配置与特征哈希，防止“旧模型配新数据”。
