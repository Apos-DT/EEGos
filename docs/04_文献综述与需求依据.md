## 2. 情绪表示与标签

### 2.1 离散模型

将情绪划分为有限类别（如高兴、悲伤、恐惧、愤怒、平静）。优点是分类目标明确、便于监督学习；缺点是不同的受试者/文化对同一标签的理解不同，边界模糊。SEED 使用三类（积极/中性/消极），SEED-IV 使用四类，MPED 使用七类（六种基本情绪+中性），FACED 使用九类（四正、四负、中性）[21][22][24][26]。

### 2.2 维度模型

用效价（valence，愉快–不愉快）和唤醒（arousal，平静–激烈）描述情绪，常配合 SAM（Self-Assessment Manikin）9 点量表。DEAP 让被试对每个 1 min 音乐视频评分 arousal、valence、liking、dominance、familiarity [23]；本课题的预评价问卷同样采用 9 点效价/唤醒 + 离散主导情绪 + 明确度/稳定性/熟悉度等辅助题。

### 2.3 本项目的标签策略

- **主标签**：四象限（HVHA/HVLA/LVHA/LVLA），与刺激预设和连续评分同时对应；
- **辅助标签**：离散主导情绪（5–7 类），用于细粒度分析；
- **连续标签**：效价/唤醒均分，用于回归/相关性/标签一致性分析；
- **质量标签**：0–100 质量分与 S/A/B/C/D 等级，只表示材料可用性，不进入情绪分类标签。

> 重要：预设情绪 ≠ 被试实际情绪。系统保留“预设—实际”两套信息，并在数据字典中强制区分，避免论文把材料标签当作真值。

**对本项目数据制备的启示**：

1. **刺激时长**：DEAP 用 1 min，MPED 用 2.5–5 min，FACED 平均 66 s（34–129 s）。本项目视频 114–297 s、音乐标注片段 23–167 s，需统一分析窗口，不能直接混用。
2. **通道/采样率**：62 导/1000 Hz 与 32 导/250 Hz 是两条常见路线；系统必须把通道名、采样率、单位写入 manifest。
3. **标签**：离散与维度标签并存是常态；只保留一种会限制后续分析。
4. **被试量**：FACED 的 123 人说明大样本是趋势；本项目 ≥30 人才能支撑跨被试结论。
5. **可获取性**：公开数据需申请/签署协议，论文必须写清版本与预处理，不能只写数据集名称。

## 4. 技术路线与研究现状

### 4.1 经典 pipeline

综述普遍将 EEG 情绪识别分为：信号采集 → 预处理（滤波、伪迹去除、重参考）→ 特征（时域/频域/时频/空间）→ 特征选择/降维 → 分类/回归 [1][3][28]。DE（微分熵）在 5 个频带上被广泛使用，SEED 系列工作将其作为标准特征之一 [1][21]。

### 4.2 被试依赖 vs 被试独立

- **被试依赖**：同一被试的数据同时用于训练和测试，性能通常较高，但不能回答“新用户能否直接用”；
- **被试独立**：测试被试不参与训练，考察泛化；按训练时可见的目标域信息 further 分为：
  - 域泛化（DG）：只用源域；
  - 无监督域适应（UDA）：可用目标域无标签数据；
  - 半监督域适应（SSDA）：可用少量目标域标签 [1][6]。

本课题以 **UDA/LOSO** 为主，因为实际应用更接近“新被试、无标签”。

### 4.3 代表性跨被试方法

| 方法 | 核心思想 | 证据/备注 |
|---|---|---|
| DDA [4] | 动态域适应，类感知地对齐源/目标 | 跨被试/跨会话 |
| BiDANN [7] | 双半球域对抗 | 利用半球不对称 |
| SSAS [6] | 先选源域、再加权对抗适应 | 解决负迁移；SEED/SEED-IV |
| CLISA [15] | 对比学习对齐同刺激下不同被试的表示 | 学习被试不变表征 |
| GMSS [16] | 图 + 多任务自监督（空间/频率拼图、对比） | SEED/SEED-IV/MPED |
| DMMR [17] | 去噪混合互重建，两阶段预训练+微调 | SEED 88.27±5.62，SEED-IV 72.70±8.01 |
| MIND-EEG [12] | 多粒度空间整合 + 离散码本 | 全局/区域/区域间 |
| PCL-TDGCN [13] | 动态图 + 原型对比 | 时空动态连接 |
| TAHAG [14] | 两阶段域适应 + 混合自适应图 | 图结构对齐 |
| MSHCL [18] | 多尺度双曲对比 | 层级结构建模 |
| Sera [11] | 由粗到细的表示对齐 | 跨域细粒度 |
| CMJDA [5] | 多模态半监督域适应 | 多模态 |
| DAPLP [9] | 伪标签传播 | 无监督 DA |
| MSGDAN [10] | 多源选择图域适应 | 多源域 |
| TT-CDAN [8] | 条件对抗域适应 | 类条件对齐 |
| Info Fusion [19] | EEG+眼动，区域到全局，时空语义对齐 | 多模态融合 |

**共同趋势**：

1. 从“全局分布对齐”走向“类条件/原型/图结构对齐”；
2. 从“单源域”走向“多源选择/源权重”；
3. 从“静态图”走向“动态图”；
4. 从“单模态”走向“多模态”；
5. 从“单点精度”走向“稳定性/最差被试/可解释性”。

### 4.4 研究缺口

| 缺口 | 表现 | 本项目对应 |
|---|---|---|
| G1 数据制备不可复现 | 只写“参照 SEED”，没有清洗规则/质量分/选材记录 | 审计 + 质量门控 + 选材清单 |
| G2 标签不确定性 | 预设标签与被试体验不一致，未报告一致率 | 预设/实际双标签 + 一致率 |
| G3 评估泄漏 | 标准化/早停/调参使用测试被试 | LOSO + 被试隔离 + 断言 |
| G4 跨刺激类型迁移 | 视频训练→音乐测试的研究少 | 数据协议支持双模态 |
| G5 类内多模式 | 单原型难覆盖同类的多子模式 | 多原型设计 |
| G6 工程与科研脱节 | 脚本硬编码、结果不可追溯 | 配置/清单/报告一体化 |

## 6. 研究框架与假设

### 6.1 框架

```text
刺激质量与标签一致性（数据侧）
        ↓
DE 特征（通道×5 频带）
        ↓
双视角编码：电极视角 + 脑区视角
        ↓
融合表示 → 分类
        ↓
类内多原型正则：紧凑性 + 类间 margin
        ↓
LOSO 评估：ACC / Macro-F1 / κ / 最差被试 / 95% CI
```

### 6.2 假设

- **H1（双视角）**：在相同特征与划分下，双视角融合的 Macro-F1 高于任一单视角；
- **H2（多原型）**：当同类样本存在多子模式时，多原型比单原型有更低的类内距离和更高的最差被试精度；
- **H3（稳定性）**：双视角+多原型的跨被试精度方差/最差被试指标优于基线，而不仅是均值略高。

### 6.3 竞争性解释

- 提升可能来自参数量增加，而非结构本身 → 需参数量匹配的对照；
- 提升可能来自原型正则的正则化效应 → 需去掉原型的消融；
- 提升可能对超参敏感 → 需固定搜索空间与预算，报告均值±标准差。

## 7. 评估规范（论文必须报告）

1. **划分**：LOSO，测试被试不参与任何拟合；验证集只来自训练被试；
2. **指标**：Accuracy、Balanced Accuracy、Macro-F1、Cohen's κ；分类别 P/R/F1；
3. **不确定性**：至少 1,000 次 bootstrap 的 95% CI，或每折均值±标准差；
4. **最差被试**：跨被试研究应报告 worst-subject，避免均值掩盖失败；
5. **随机水平**：1/K，并在图中标出；
6. **统计检验**：配对 Wilcoxon / Friedman + Nemenyi（多模型）；
7. **消融**：双视角、原型数、域适应损失分别开关；
8. **可复现**：数据版本、通道、采样率、滤波、窗口、种子、代码提交号。

## 9. 对本项目的直接结论

1. **数据侧必须先做审计与质量门控**：现有 240 条材料、2,356 条问卷是宝贵资产，但编号/文本锚点/播放问题/时长不一致会直接污染标签。
2. **模型侧先做可靠的 LOSO 基线**：没有无泄漏的基线，任何“创新”都不可信。
3. **创新点应聚焦“类内多模式 + 双空间粒度”**：这与现有单原型/单视角方法形成可检验差异，且可在小样本上做消融。
4. **论文必须报告最差被试与置信区间**：跨被试研究的均值容易掩盖失败。
5. **工程侧必须保留数据血缘**：这既是软件工程要求，也是科研可复现的底线。
