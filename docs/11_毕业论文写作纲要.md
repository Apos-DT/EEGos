## 1. 选题定位

### 1.1 题目建议

优先：

> **面向跨被试脑电情绪识别的数据制备与模型训练系统设计与实现**

备选：

- 融合双视角与多原型的跨被试 EEG 情绪识别方法研究与系统实现
- 脑电情绪识别数据集质量门控与可复现训练平台的设计与实现
- 面向视频/音乐刺激的 EEG 情绪识别数据制备与评估系统

**注意**：题目同时包含“数据/系统”和“方法/模型”，避免被评审认为只是“做了一个网页”或“只跑了一个模型”。

### 1.2 研究问题

- RQ1：如何把刺激预评价转化为可执行、可审计的材料选择规则？
- RQ2：如何构建无泄漏、可复现的 EEG 情绪识别训练评估流水线？
- RQ3：双视角 + 类内多原型能否提升跨被试情绪识别的稳定性？

### 1.3 创新点（克制表述）

1. **数据侧**：面向视频/音乐双刺激的质量门控与平衡选材流程，把“材料质量”从经验判断变为可计算、可复核的指标；
2. **方法侧**：电极视角 + 脑区视角的双空间粒度建模，并用类内多原型刻画同一情绪下的多种模式；
3. **工程侧**：数据血缘、LOSO 防泄漏、报告一体化，使科研结果可复现。

> 不要写“首次提出”“国际领先”。本科论文的创新点应是“组合创新 + 工程落地 + 可验证改进”。

## 4. 实验设计（论文第 5 章）

### 4.1 数据

- 自采：≥30 被试，视频/音乐各 40 trial（每类 10）；
- 公开：SEED（跨被试主基线）、DEAP（连续标签/跨被试）；
- 预处理：0.1–70 Hz 带通、50 Hz 陷波、200 Hz 重采样、1 s 窗 DE；
- 标签：四象限为主，离散为辅。

### 4.2 划分

- 主设置：LOSO；
- 辅助：被试依赖（上界参考）；
- 验证：每折从训练被试中分层切 20%；
- 禁止：测试被试参与标准化/早停/调参。

### 4.3 对比

| 类型 | 方法 |
|---|---|
| 传统 | SVM + DE |
| 深度特征 | MLP、DGCNN |
| 原始波形 | EEGNet |
| 域适应（可选） | DANN/MMD、CLISA 复现 |
| 本文 | DualView、DualView+MultiProto |

### 4.4 指标

ACC、Balanced ACC、Macro-F1、κ、95% CI、最差被试、分类别 P/R/F1、混淆矩阵。

### 4.5 消融

- 单电极视角 / 单脑区视角 / 双视角；
- 原型数 K=1/2/4；
- 原型损失权重 λ=0/0.05/0.1/0.2；
- 有无域适应（若实现）。

### 4.6 统计

- 每折均值±标准差；
- 配对 Wilcoxon（本文 vs 基线）；
- Friedman + Nemenyi（多方法）；
- 报告效应量/置信区间，不只报 p 值。

### 4.7 失败分析

- 最差被试的混淆矩阵；
- 标签一致率低的类别；
- 通道/频带消融；
- 数据质量问题（播放、时长、伪迹）。

## 8. 常见答辩问题

| 问题 | 回答要点 |
|---|---|
| 你的创新点是什么？ | 数据门控+双视角+多原型的组合，重点在“可验证的稳定性提升”，不夸大 |
| 为什么不用端到端？ | 数据量小、DE 可解释、CPU 可复现；EEGNet 作为对照 |
| 如何保证没有泄漏？ | LOSO、验证集来自训练被试、标准化只在训练折、代码断言 |
| 为什么准确率不高？ | 跨被试本身难；报告最差被试/CI；分析标签与伪迹 |
| 数据质量分怎么来的？ | E/C/L/D/N + 播放门控；复用既有评分并交叉核对 |
| 系统有什么工程价值？ | 可审计、可复现、可扩展；一条命令出报告 |
| 为什么音乐结果差？ | HVLA 标签命中率 17%，材料问题；已给出替换建议 |
| 你的方法和 SSAS/CLISA 比？ | 同划分/同特征/同预算；若未复现，明确说明限制 |
| 样本量够吗？ | 自采≥30；公开数据交叉验证；报告 CI |
| 伦理怎么做的？ | 批件、知情同意、伪匿名、可退出 |
