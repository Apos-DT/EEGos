## 1. 背景与问题定义

### 1.1 研究背景

情绪识别是人机交互、心理健康辅助、教育状态监测等应用的共性技术。相比面部表情、语音和文本，EEG 直接记录大脑活动，具有不易伪装、时间分辨率高的特点，适合研究情绪诱发过程中的动态变化。近年来，公开数据集（SEED、SEED-IV、DEAP、MPED、FACED 等）和跨被试域适应方法（DDA、SSAS、CLISA、GMSS、DMMR 等）快速发展，但研究实践中仍存在三类“最后一公里”问题：

1. **数据来路不清**：刺激材料如何筛选、问卷如何清洗、质量分如何计算，论文中往往只写一句“参照 SEED”；
2. **标签不可追溯**：预设情绪、被试实际体验、离散标签与连续标签之间的关系没有被记录，导致“同名不同义”；
3. **评估不可复现**：跨被试划分、标准化、早停、超参选择存在隐性泄漏，结果难以复现。

### 1.2 工程问题

课题组目前已有 240 条视频/音乐刺激、2,356 条预评价问卷和两套质量评分结果，但缺少一个把“材料—问卷—质量—EEG—特征—模型—报告”串起来的软件系统。现有脚本能完成单点分析，却存在路径硬编码、字段语义分散、结果不可追溯等问题。

### 1.3 研究问题

本项目聚焦：

> **在跨被试、跨刺激类型条件下，如何构建一个可审计、可复现的 EEG 情绪识别数据制备与模型训练系统，并在该系统上验证双视角多原型方法的有效性？**

分解为三个子问题：

- RQ1：如何把刺激预评价与质量门控转化为可执行的实验材料选择规则？
- RQ2：如何保证从原始 EEG 到特征、划分、训练、评估的全链路无标签/被试泄漏？
- RQ3：双视角（电极/脑区）与类内多原型能否在跨被试设置下提升情绪分类的稳定性？

## 2. 项目目标与范围

### 2.1 总目标

交付一套**可直接用于课题组 EEG 情绪识别研究**、同时**满足软件工程本科毕业设计规范**的系统与文档：

- 数据侧：刺激库、问卷清洗、质量评分、平衡选材、EEG 预处理、DE 特征、数据集清单；
- 模型侧：被试依赖/跨被试训练、MLP/DGCNN/DualView/EEGNet 基线、LOSO 评估、统计与报告；
- 工程侧：需求、设计、测试、用户手册、配置管理、论文纲要、符合性矩阵；
- 研究侧：在真实数据上完成至少一轮可复现实验，形成论文可用的图表与结论。

### 2.2 本期（V1.0）范围

| 纳入 | 不纳入 |
|---|---|
| 现有 240 条刺激与 2,356 条问卷的审计 | 重新采集 240 条材料 |
| 80 条平衡选材示例 | 正式实验全部被试采集 |
| `raw.npz → DE → 训练` 流水线 | EDF/BDF 原始文件的高层解析（预留 MNE 适配） |
| LOSO 与被试依赖两种设置 | 在线实时 BCI 推理 |
| DualView-MultiProto 原型实现 | 大规模超参搜索/神经架构搜索 |
| CLI + 本地 Web 控制台 + HTML 报告 | 多用户/公网平台 |
| 合成数据软件验收 | 自采 EEG 的最终科研性能结论 |

### 2.3 成功标准

1. 需求文档中的 P0 功能全部有代码与测试证据；
2. 实际数据审计结果与既有质量报告一致（问题视频 22/29 条）；
3. 自采 EEG 到位后，研究者仅需准备 `raw.npz` 即可在 1 天内跑通 LOSO；SEED-IV 已作为外部验证接入。
4. 论文能完整回答 RQ1–RQ3，且所有数字可由仓库命令复现；
5. 通过指导教师与答辩小组的软件工程规范审查。

## 3. 技术可行性

### 3.1 数据基础

- 刺激：视频 120 段、音乐 120 首，四象限各 30，类别平衡；
- 问卷：视频 1,269 条、音乐 1,087 条，包含效价、唤醒、主导情绪、明确度、覆盖时长、稳定性、熟悉度、理解度、播放问题；
- 质量：已有两套 0–100 分排序，含 S/A/B/C/D 等级、置信区间、稳健性检验；
- 缺口：**自采原始 EEG 尚未进入工作区**；但 **SEED-IV 官方特征已接入**，已完成 15 折 LOSO 的 MLP 基线（42.78%）与 DualView 初步结果（27.69%）。自采设备的通道/事件/伪迹门禁仍需执行。

### 3.2 技术路线可行性

| 环节 | 方案 | 可行性依据 |
|---|---|---|
| 问卷清洗 | 规则 + 显式别名 + 审计日志 | 已在真实数据上验证，重复数/问题数与既有报告一致 |
| 质量评分 | 复用既有 E/C/L/D/N + 播放门控 | 已有 120+120 条结果与稳健性分析 |
| 选材 | 模态×象限分层，等级优先 | 80 条示例全部 B 级以上 |
| 预处理 | SciPy 零相位滤波/陷波/重采样 | 依赖少、可单测；MNE 作为可选扩展 |
| 特征 | 5 频带 DE（1 s 窗） | 与 SEED/MPED 常用做法一致 |
| 模型 | MLP/DGCNN/DualView/EEGNet | PyTorch 已安装，CPU 可跑小规模 |
| 评估 | LOSO + 被试隔离 + OOF 指标 | 代码含泄漏断言与单测 |
| 报告 | HTML/JSON/PNG | 已生成可读报告 |

### 3.3 关键算法可行性

- **DualView-MultiProto**：电极视角用共享通道编码 + 注意力池化；脑区视角用连续分区 + 区域注意力；融合后分类；类内多原型用“最近原型距离 + 类间 margin”正则。参数量小，CPU 可训练，便于消融。
- **LOSO**：每折留一名被试，验证集只从其余被试切分，标准化只在训练折拟合；代码有 `assert_no_subject_leakage`。
- **可解释性**：电极/区域注意力权重、原型距离、混淆矩阵可作为论文分析材料。

### 3.4 技术风险

| 风险 | 概率 | 影响 | 对策 |
|---|---|---|---|
| 自采 EEG 采集延迟 | 高 | 高 | 已用 SEED-IV 完成真实数据基线；自采协议并行推进 |
| 设备/事件格式不统一 | 中 | 高 | 定义 `raw.npz` 契约；MNE 适配器后置 |
| 标签噪声 | 高 | 中 | 保留连续标签与离散标签；报告标签一致率；剔除/敏感性分析 |
| 跨被试性能低 | 中 | 高 | 以 LOSO + 多基线 + 置信区间报告，不追求单点 SOTA |
| 工作量超期 | 中 | 高 | MVP 优先级；先 P0 后 P1；文档与代码同步迭代 |

## 5. 操作可行性

### 5.1 使用者与流程

- **数据管理员**：导入问卷/映射/媒体，运行 `audit`，处理问题清单；
- **实验员**：按 `select` 输出准备材料，执行采集，登记被试/会话/Trial；
- **算法工程师**：准备 `raw.npz`，运行 `features`/`train`，查看报告；
- **导师/评审**：阅读 HTML/Word 报告与测试证据。

### 5.2 部署

- 单机 Windows/Linux，Python 3.11+；
- CLI + 本地 Web 控制台，无需数据库/服务器；
- 数据以文件目录 + NPZ + JSON 清单管理，便于备份与归档；
- 后续可加 Streamlit/Web，但不影响核心流水线。

### 5.3 运维

- 所有输出带时间戳、配置、SHA-256；
- 日志与异常信息写入 `artifacts/`；
- 通过 `unittest` 与固定种子实现回归。

**结论**：操作上可行，学习成本低。

## 6. 法律、伦理与合规可行性

### 6.1 伦理

- 自采 EEG 必须通过单位伦理审查/备案，签署知情同意书；
- 被试可随时退出，数据可撤回；
- 情绪诱发材料可能引发不适（尤其恐惧/悲伤），需设置休息、终止规则与心理支持；
- 不得把系统输出用于临床诊断或招聘/教育等高风险决策。

### 6.2 隐私

- 被试 ID 伪匿名化，姓名/学号/联系方式与 EEG 分离存放；
- 报告只显示 `S01` 等伪 ID；
- 原始数据访问受控，对外只发布特征/聚合结果；
- 建议对含面部视频的数据做单独授权与脱敏。

### 6.3 版权

- 视频/音乐刺激仅用于研究，不随论文/仓库公开；
- 公开数据集遵循原许可证与引用要求；
- 论文中使用的截图/波形需注明来源。

**结论**：在完成伦理审批与数据授权的前提下可行；否则只能使用公开数据做方法研究。

## 7. 进度可行性

16 周计划（详见 `03_项目计划与WBS`）：

- 第 1–4 周：文献、需求、数据审计、方案；
- 第 5–8 周：材料筛选、采集/预实验、预处理与特征；
- 第 8–12 周：模型、LOSO、消融；
- 第 12–14 周：系统测试、可用性、论文初稿；
- 第 15–16 周：查重、定稿、答辩。

关键路径是**自采 EEG 的采集与伦理审批**。SEED-IV 已接入并作为真实数据基线；若自采延迟，可继续用公开数据完成方法验证，自采数据作为扩展。

**结论**：按 MVP 范围可行；若要求大规模自采+完整消融，需延长 4–6 周或缩减被试量。

## 8. 备选方案比较

| 方案 | 描述 | 优点 | 缺点 | 结论 |
|---|---|---|---|---|
| A. 纯算法复现 | 只实现一个域适应模型 | 工作量小 | 不满足“系统”与数据制备要求 | 不选 |
| B. 纯数据平台 | 只做问卷/质量/选材 | 数据价值高 | 缺模型训练，毕业设计不完整 | 不选 |
| C. 数据+模型一体化（本项目） | 审计、选材、特征、训练、报告 | 完整、可复现、可论文 | 工作量大，需控制范围 | **选用** |
| D. 多模态大平台 | EEG+眼动+心电+面部 | 创新点多 | 风险高、难在 16 周完成 | 不选 |

## 9. 结论

**项目可行，建议立项。**

- 技术：核心流水线已实现并通过 28 项测试（含 4 项 Web 测试）；SEED-IV 已接入并跑通 15 折 LOSO；
- 经济：开源栈、复用现有数据，成本低；
- 操作：CLI 单机可运行，流程清晰；
- 伦理：需先完成审批与知情同意；
- 进度：按 MVP + 公开数据兜底可在 16 周内完成；
- 主要不确定性：原始 EEG 到位时间、标签质量、跨被试性能。应通过“先软件后数据、先基线后创新、先小样本后扩展”的顺序控制风险。

**建议的决策点**：

1. 第 4 周末：确认标签体系与采集协议；
2. 第 8 周末：完成 5–10 人预实验并冻结预处理参数；
3. 第 12 周末：完成主实验，锁定论文数字；
4. 第 14 周末：完成系统验收与论文初稿。
